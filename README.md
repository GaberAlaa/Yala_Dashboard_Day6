Sales Performance Dashboard

This Power BI dashboard provides a high-level analysis of sales performance,
customer engagement, and product distribution across four key regions: Midwest, Southeast, Northeast, and West.

Key Performance Indicators (KPIs)

- Total Sales: $23.14M in total revenue.
- Order Volume: 6,912 total orders processed.
- Average Order Value (AOV): $3.35K per transaction.
- Web Engagement: 9,073 total Web Events tracked.

Core Analysis
- Product Distribution: Sales are broken down by category, with Standard paper leading at 41.8%, followed by Gloss (32.81%) and Poster (25.39%).
- Top Sales Personnel: Tracks individual representative performance, led by Earlie Schleusner ($1.10M) and Tia Amato ($1.01M).
- Major Clients: Identifies highest-value customers, including EOG Resources ($0.38M) and Mosaic ($0.35M).
- Growth Trends: A dual-axis time-series chart analyzes the correlation between Sales and Web Events from 2014 to 2017,
- visualizing a significant growth trajectory over the three-year period.
